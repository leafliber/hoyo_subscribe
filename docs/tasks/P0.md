# P0 · 平台、来源、模型与日历主通道验证

> 唯一主要目标：**在写任何业务代码之前，确认这套方案依赖的四件外部事实是否成立。**
> 依据：主方案 §2.2—§2.4、§3.1、§3.5、§6.2、§10.4。

## 阶段性质：这一阶段大部分不是编码

真实 Cloudflare 账户资格、真实发信、真实账单、真实日历客户端，执行者 Agent 无权也无法完成。Agent 的交付是：**只读探测代码、采集脚本、证据登记模板、结论表骨架，以及一份"需所有者执行的操作清单"**。

三条铁律：

1. **不得用模拟结果填充 P0 证据。**探针跑不通就如实记录跑不通。
2. **不得开通任何收费资源、不得发送真实邮件、不得升级计划。**需要这些时写进"需所有者执行"清单。
3. **P0 未完成不等于可以跳过。**"先把账号中心做完"不是放行替代（§10.4）。P1/P2/F1/F2 可并行推进，但 P3 之后的放行受 P0 结论约束。

- 模型探针只用合成样本，样本文件显式标 `synthetic: true`。

**不在范围**：任何业务表、任何写操作、任何发信。

**回退点**：`scripts/probes/` 与 `docs/evidence/` 可整体删除，不影响其他目录。
