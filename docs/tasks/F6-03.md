## 交付物

1. 中文与既有英文兑换码共享 contracts 校验，真实官方样本能够完成采集、正文读回、规则发布和公开读取；不放宽 HTML、分隔符与控制字符限制。
2. 独立 `/admin/redeem-codes/`，包含直播来源开关、维护解除、活动登记、兑换码与截止时间；设置页不再嵌入兑换码管理；空列表及读取失败不误报官方未发放。
3. 版本时间表按保存的确认值区分待选择/已选择节点，未完成优先，已完成版本收起；修改、清除、下一版本引用及 CAS 维持原行为。
4. 标准八项命令、真实样本离线回归、桌面与手机浏览器验证和截图；按 AGENTS.md §5 报告并提交一个 PR。

## 不在范围

生产部署或数据写入；新来源、新供应商；真实邮件/Push/模型调用；手填版本时间、自动确认、批量审核；F6-02 的投递终态解除；其他任务卡与验收导航维护。
