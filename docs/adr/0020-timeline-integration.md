# ADR-0020：时间轴整合——今天总在轴上，回看昨天接在主轴上，时间待定单独成卡

- **状态**：已接受（F1-09 实施）
- **日期**：2026-10-06
- **提出者**：所有者
- **需要所有者批准**：是，已批准。所有者 2026-10-06 原话：
  1. "在今天没有日程的时候，当前时间的横线会意外消失，修复该问题"；
  2. "回看昨天是在日程时间轴上接上，不是单独开一个时间轴"；
  3. "时间待定单独列为一个卡片放在下面，默认折叠"；
  4. "整体优化时间轴的显示"。
- **与已有 ADR / 决定的关系**：
  - 改变 ADR-0017 的版面："标题 → 回看昨天 → 当前范围逐日 → 末行 → 时间待定"。昨天仍在顶部，但改为主轴的第一行；时间待定移出时间轴卡片。
  - ADR-0015 的时间轴跨日连续、待定默认折叠保持不变。

## 背景

- **时刻线消失**："现在"标记只插在今天那一组的精确时间列表里。今天没有活动时没有这一组，标记跟着消失；今天只有全天条目时也一样。2026-10-06 线上即是如此。
- **回看昨天**：是一个带底色的折叠块，展开后里面是独立的短列表，轨道首尾各自封口，与下方的主时间轴断开。
- **时间待定**：在时间轴卡片底部，与时间轴挤在一张卡片里。
- **日期点**：通用条目圆点规则写在日期点规则之后、优先级相同，覆盖了日期点的样式。除今天外，日期点都画成无边框的白点，看起来像轨道断了一截（ADR-0015 起即如此）。

## 受影响的合同

| 文档 | 章节 | 现有规定 | 本 ADR |
| --- | --- | --- | --- |
| 前端 | §4.1 页面骨架 / D1′ | 回看昨天在时间线顶部，默认折叠，折叠时只占一行（ADR-0017） | 回看昨天是主时间轴的第一行：与条目同一网格，轨道从这一行的图标处开始。展开后昨天的日期段落用与其他日期相同的版式，同一条轨道穿过，接在今天之上。仍默认折叠 |
| 前端 | §4.3 / ADR-0015 | 时间待定默认折叠，在时间轴末尾 | 时间待定是时间轴卡片下方单独一张卡片，默认折叠，展开状态随重绘保留 |
| 前端 | §4.3 "现在" | 今天列表里过去与未来的分界线 | 今天总在时间轴上：今天没有安排时画出今天（"暂无安排"）与时刻线；今天只有全天条目时，时刻线在全天条目之前 |

公开接口、窗口档位、排序规则（`compareScheduleNodes`）、"显示更多"与末行都不变。"当前范围"仍只指 `[data-region="days"]`：昨天的段落不放进这个区域，显示更多、滚动锚定与计数都不受影响。

## 决策

1. **今天总在**：
   - 当前范围不为空、但没有今天的条目时，补一个空的今天：日期行写"暂无安排"，带"现在"时刻线。
   - 今天只有全天条目时，时刻线单独成列表，放在全天条目之前。
   - 当前范围为空时仍显示空态，不额外画今天。
2. **回看昨天接在主轴上**：
   - 折叠时是轨道上的一行：时间列空、轨道上是"历史"图标，内容列是"回看昨天（日期）N 项"，末尾是展开箭头。
   - 展开后，昨天按普通日期段落画出（日期标记、条目、已过降权），与下方共用一条轨道。
   - 当前范围为空时，折叠的这一行不画轨道。
3. **时间待定单独成卡**：时间轴卡片之后单独一张卡片，外观与"近期重要变更"一致（图标、标题、条数、展开箭头），默认折叠。
4. **时间轴显示优化**：
   - 修正日期点被覆盖的问题，日期点恢复为实心圆角方块；今天的日期与日期点用强调色。
   - 日期之间多留一点间距，轨道照常穿过。
   - 已过去的条目，标题与动作改用次要文字色。不降不透明度，对比度不打折（U28）。
   - "现在"标签改为红底白字的小胶囊，配色沿用已登记的"危险按钮文字 on 错误色"组合。
   - 窄屏（≤ 640 px）原本就不显示条目末尾的箭头列，保持不变。

## 价值

- 任何时候都能在时间轴上看到"今天"和"现在"的位置。
- 昨天与今天、以后读起来是同一条线。
- 时间未知的条目不再挤在时间轴里。
- 日期点不再像断轨。

## 成本

- 回看昨天在折叠时仍只占一行。
