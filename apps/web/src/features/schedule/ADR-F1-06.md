# ADR-F1-06：公共 API 接入需要详情静态壳路由及昨天数据边界裁定

- **状态**：提议
- **日期**：2026-10-01
- **提出者**：F1-06 执行者
- **需要所有者批准**：是（任务卡范围扩展与浏览语义裁定，不涉及收费或权限扩大）

## 背景

F1-06 要求“移除构建期静态生成的 synthetic 详情页，详情改为按请求读取”，前端 §2.1 的详情路径为 `/events/{event_id}`，§12.1 沿用“Astro 静态页面与小型 TypeScript 模块”。当前 `astro.config.mjs` 只输出静态页，`scripts/e2e/serve.mjs` 只服务实际文件，Worker 尚未配置静态资源。仅修改 `[event_id].astro` 无法让任意真实 ID 的直接请求或刷新命中静态壳。

D1′ 要求“列表最下方固定附加一条‘昨天’分组，[昨日 00:00, 今日 00:00)，……常驻的回看出口”。P3-14 `publicNodeInWindow` 与交接明确“all 也只取本代今天起的节点”，API 不接受昨天或任意历史范围。不能用空数组声称昨天没有安排，也不能把近期更正当成完整昨天列表。

另外，现有 `schedule-browse.ts` 的时间、动作与筛选纯函数参数绑定 `ScheduleNode / ScheduleSnapshot`（公告时间不可 null、change 是样例联合、synthetic 必须 true），真实响应无法直接调用。不能把真实数据伪装为 synthetic 快照，也不能在前端复制业务判断。

## 受影响的合同

| 文档 | 章节 | 现有规定 | 拟改为 |
| --- | --- | --- | --- |
| 前端设计 | §2.1、§5、§12.1 | 固定详情 URL，静态页面、按需读取 | 保持不变；补静态壳路由基础设施 |
| F1-F2 任务卡 | F1-02 D1′ | 昨天常驻回看 | 待裁定：API 补昨天，或本卡明确显示“昨天数据暂不可用”并登记后续卡 |
| AGENTS | §2 参数与业务规则单源 | contracts 纯函数共用 | 保持不变；将现有浏览函数的输入改为实际所需字段并支持公共节点集合 |

## 决策（待批准）

建议：
1. 保留纯静态 Astro，详情只构建一个无事实数据的公共壳。新增 `apps/web/public/_redirects`，仅将 `/events/*` 重写到该壳；最小扩改 `scripts/e2e/serve.mjs`，让本地服务遵循同一路由映射。请求保留原 event_id，由 TS 模块调用已定详情 API。测试只拦截 API，不拦截 HTML 导航。生产静态资源绑定仍交部署卡，报告注明。
2. 先保留昨天区域并明确写“当前公共接口不提供昨天数据，暂无法回看”，不宣称已实现昨天回看；若要求本卡完整保持 D1′，需另授权后端与 contracts 的窗口扩展并先定合同。
3. 最小扩改 `packages/contracts/src/schedule-browse.ts` 及对应测试：现有展示函数改为字段子集输入；抽出通用节点分组/浏览筛选函数供真实接口和既有样例测试共同使用。不修改 `public-api.ts` 响应形状、不新增参数或业务规则。

## 价值

真实事件详情可以直接打开和刷新；e2e 验证实际静态路由。昨天不可读会被明确说明，不产生假空结果。时间与筛选规则继续单源。

## 成本

无依赖、数据库迁移和数据回填。路由映射及纯函数签名增加最小变更；真实昨天回看若要实现，需要后端另行提供数据。

## 安全影响

静态重写仅限 `/events/*`，不覆盖 `/api/*`、私人 Feed、认证和退订路径。event_id 经 URL 编码后请求公共 API；不读取 Cookie，不发送认证凭证。证据与公告片段使用 textContent。

## 预算与容量影响

不改变邮件日池、模型预算、账号、Feed 容量或 A.5 等式。详情静态壳无需 SSR。若扩展昨天查询，后端仍须遵守 P3-14 的有界分页及 rows_read 保护，不能绕过现有上界。

## 回退

回退本卡代码即可；没有迁移、外部发送或生产资源操作。原开工基线为 e3a7b3f7f66913718d90a802f1be45dbc3e80c2a；2026-10-01 继续时已快进到 origin/main 的 4ff7645。

## 备选方案

- SSR：需要适配器/部署配置，超出本卡且与零新增依赖要求不符。
- 构建时枚举真实事件：发布后新增事件无法直接打开，违背按请求读取。
- 仅测试中拦截 HTML 返回壳：掩盖真实路由缺失，不采用。
- 前端复制业务规则或强转 synthetic：违反规则单源与 P3-14 交接，不采用。
